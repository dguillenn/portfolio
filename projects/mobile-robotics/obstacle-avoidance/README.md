# Obstacle Avoidance

**Skills:** Mobile Robotics, Autonomous Navigation, Virtual Force Fields (VFF), Obstacle Avoidance, Laser Processing, Python

## Overview

This project implements a Virtual Force Field (VFF) navigation algorithm for autonomous obstacle avoidance.

The method combines attractive forces generated by the target location and repulsive forces generated by nearby obstacles. The resulting force determines the robot's movement, allowing it to safely navigate through the environment while avoiding collisions.

## Objective

Implement a Virtual Force Field (VFF) algorithm where:

- Obstacles generate repulsive forces that push the robot away.
- The target generates an attractive force that pulls the robot toward the goal.
- The robot selects a safe path by combining both effects.

## Technologies

- Python
- Laser Sensor
- Virtual Force Fields (VFF)
- Autonomous Navigation

## Method

### Laser Data Processing

The first step consists of processing the laser sensor data and converting it into Cartesian coordinates.

Only obstacles closer than 2 meters are considered, since distant objects do not represent an immediate risk.

For each laser ray, a repulsive force is generated according to its distance and angular position:

#### Obstacles in Front of the Robot (±30°)

```python
2.5 / r**1.5
```

These obstacles generate the strongest repulsive force.

#### Obstacles Between 30° and 60°

```python
1 / r**1.5
```

These obstacles generate a moderate repulsive force.

#### Obstacles Beyond 60°

```python
0.8 / r**1.5
```

These obstacles have a smaller influence on navigation.

Each obstacle produces a repulsive vector proportional to:

```text
1 / r^1.5
```

where `r` is the obstacle distance.

All repulsive vectors are summed to obtain the total repulsive force.

### Attractive Force Calculation

The attractive force is calculated using the target position.

The `absolute2relative()` function converts the global target coordinates into coordinates relative to the robot reference frame.

The attraction vector is limited between minimum and maximum values to ensure smooth motion:

- When the target is far away, the robot does not accelerate excessively.
- When the target is close, the robot continues moving without stopping abruptly.

This produces a stable approach toward the destination.

### Force Combination

The navigation vector is obtained by combining the attractive and repulsive forces:

```text
Total Vector = katt · Attractive + krep · Repulsive
```

where:

- `katt` controls the attractive force contribution.
- `krep` controls the repulsive force contribution.

The resulting vector determines the robot motion:

- The vector angle is used to compute angular velocity.
- The attractive force magnitude influences linear velocity.

### Brake Factor

A brake factor was introduced to improve safety near obstacles.

The brake factor depends on the magnitude of the total repulsive force.

When obstacles are close:

- Repulsive force increases.
- Linear velocity decreases.

When obstacles are far away:

- Repulsive force decreases.
- The robot moves faster.

This mechanism produces smoother turns and safer obstacle avoidance behaviour.

### Target Switching

When the robot reaches a distance smaller than 2 meters from the current target, it automatically switches to the next waypoint.

This prevents oscillations around the goal position and improves navigation efficiency.

## Challenges and Solutions

### Oscillations Near Walls

#### Problem

Initially, the robot oscillated significantly when travelling close to walls.

The large number of laser detections generated rapidly changing repulsive forces, causing unstable motion.

#### Solution

The influence of walls was reduced by:

- Limiting the maximum distance considered by the laser.
- Reducing the weight of obstacles detected at large angles.

This produced smoother and more stable navigation in corridors and near obstacles.

### Sudden Speed Changes While Turning

#### Problem

The robot sometimes attempted sharp turns at high speed when avoiding obstacles.

This resulted in unstable behaviour and occasional collisions.

#### Solution

A brake factor based on the total repulsive force was introduced.

As obstacle proximity increases:

- Repulsive force increases.
- Linear velocity decreases automatically.

This allows the robot to slow down during manoeuvres and perform safer turns.

## Results

The implemented Virtual Force Field algorithm successfully guides the robot toward its destination while avoiding obstacles in the environment.

The combination of attractive and repulsive forces produces smooth trajectories and stable navigation behaviour.

## Conclusions

This project demonstrates how Virtual Force Fields can be used to achieve reactive obstacle avoidance using only laser sensor information.

The introduction of distance-based repulsive forces, adaptive obstacle weighting, and a brake factor significantly improved navigation stability and safety.

Although VFF provides an efficient reactive solution, future work could incorporate global planning methods to avoid local minima and improve path optimality in complex environments.
